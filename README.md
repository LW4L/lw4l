# LW4L — Lone Wolf For Life

A premium, mobile-first, display-only website. No backend, accounts, database, paid services, or build process.

## Upload to GitHub (important)

Upload **all six files directly to the root** of your existing `LW4L/lw4l` repository on the `main` branch:

- `index.html`
- `styles.css`
- `script.js`
- `lw4l-original-logo.png`
- `favicon.svg`
- `README.md`

**Do not create an `assets` folder** for this version. All website paths are relative and work on GitHub Pages project sites like `/lw4l/`.

### Updating existing files

Your repository already has some of these files. On GitHub, open each existing file, tap the pencil/edit icon, replace its contents with the updated file contents, then commit. Alternatively use GitHub's upload interface if it offers replacing existing files. Make sure `script.js` is added; it was missing from your screenshot.

### Publishing

Repository **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

After a minute or two, visit your published website and refresh. If the old version is cached, try a private tab or reload after a short wait.

### Notes

- This is an informational website, not a working Ghost Mode tracker.
- The original logo image is preserved unchanged.
- Main content stays visible even if JavaScript is blocked or fails.
- Social links are in `index.html`.
